## Submission

1. Open **Upload a mod** on [Nexus Mods](https://www.nexusmods.com/).
2. Search for both `the cabin game` and `The Cabin Game` to avoid a duplicate.
3. If absent, select **ADD NEW GAME**, enter `the cabin game`, and select **ADD GAME**.
4. Upload the usable, tested gameplay mod as the first mod for that game.
5. Record the actual approved game URL, mod URL, and file-group ID. The domain
   remains pending; `thecabingame` is only the extension's local candidate ID.

The extension upload under Modding Tools is a separate upload and does not
create a new Nexus game section by itself.
